# Sistema-de-aceleraci-n-de-capturas-de-im-genes-para-Visi-n-e-IA
Dispositivo automatizado con plataforma giratoria o brazo que captura imágenes de un objeto desde múltiples ángulos para generar datasets de entrenamiento de IA. Usa Raspberry Pi y cámara para automatizar capturas y crear datos variados para mejorar modelos YOLO de visión artificial.
